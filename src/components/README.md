# Components

All React components go here.

## Structure

- `ui/` — shadcn/ui primitives (Button, Card, Input, etc.) — generated by `npx shadcn@latest add`
- `layout/` — Layout-level components (Header, Footer, MobileNav, etc.)
- `common/` — Reusable shared components (SectionHeading, Container, Badge, etc.)
- `sections/` — Feature-specific section components, grouped by domain

## Rules

- Each section folder must own its sub-components
- No component should import from another section folder directly
- Shared logic goes to `common/` or `hooks/`
- Keep components small; extract reusable pieces into `common/`
