# Layout Components

Structural layout wrappers for consistent page composition.

## Components

- **PageContainer** — `<main>` wrapper for the page content area
- **SectionSpacing** — Consistent horizontal padding across breakpoints
- **ResponsiveContainer** — Standard centered container with responsive padding

## Rules

- These components handle ONLY layout/spacing — no visual styling
- They compose together to form the page shell
- Every page and section should use these for consistency
