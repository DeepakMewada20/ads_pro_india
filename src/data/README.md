# Data

Static content and configuration data for the website.

## What belongs here

- Navigation links
- Services content
- Pricing plans
- FAQ items
- Testimonials
- Statistics / counters
- Any other static content

## Rules

- Data files export plain objects/arrays — no components, no hooks
- Import types from `types/` to ensure type safety
- Do not put business logic here
- Do not import from outside `types/` or `constants/`
