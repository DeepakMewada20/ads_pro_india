# Lib

Pure utility functions and shared library code.

## What belongs here

- `cn()` utility (clsx + tailwind-merge)
- Framework-agnostic helpers (formatting, math, etc.)
- Third-party library wrappers (Lenis instance, animation variants)
- Service clients (API wrappers)

## What does NOT belong here

- React hooks (go to `hooks/`)
- Components (go to `components/`)
- Business logic tied to a specific feature
